# 双臂放置几何、规划终点与收尾预算修复

2026-11-17。基于 fork `main` 的 `f65ebc6`，运行代码冻结于 `99a546c2ad216b1b2de22a18608c445fef18363f`。四例代表任务均通过完整物理执行和实际动作回放；这是已知失败的修复验收，历史五种子结果仍为 cuRobo 3/5、MPLib 4/5。

## 三项改动

- **放置误拒**：将全部实际碰撞网格顶点变换到世界坐标后求紧边界，替代旋转局部 AABB 八角点。中心定义、2 mm XY 容差及原高度条件保留。旧 seed1003 的27帧归档，香蕉由0/27接受变为27/27；越界负例继续拒绝，旧报告不改分。
- **MPLib 终点**：用实际 TCP FK 核对原生 `Success`，要求位置误差≤0.5 mm、姿态误差≤1 mrad。超限时通过同一后端获得合格目标关节，并从原测得起点重新规划完整关节路径，再做原生 TOPP 和完整曲线审计。旧误差终点仅保留作诊断，不作为中途执行点；组合、持物及实际接触检查继续执行。归档的14.932/14.436 mm误差可重现，最终药瓶运行的10个终点最大误差为0.331 mm/0.496 mrad。
- **预算余量**：显式增加 `direct-release-v2`，在真实抬升及离源验证后，直接运输到原释放位姿，删除中间停靠及其3步最低预算预留。另提供经过完整末端几何检查的5 cm预抓方案。200步限制、完成时 `<200`、至少8 cm实际退手及末20步落稳保持。`standard` 仍是默认，直达策略须显式选择。

改动均在本仓库双臂扩展内；未修改安装的 MPLib、cuRobo 库或旧数据。已有双臂执行器的 CPU 自测夹具同步适配真实7D目标与FK接口，执行器运行代码未因此改变。

  --seed 401 --planner-seed 0 --approach-recipe standard-8cm \

## 保留的失败与适用范围

本轮六次失败均保留：MPLib极短修正段TOPP失败（52步）、cuRobo药瓶4 cm末端净空拒绝（10步）、水果4 cm下放原生拒绝（138步）、MPLib补尾轨迹真实碰桌（138步）、MPLib 5 cm预抓FCL测量门拒绝（38步）、水果直达后撤离原生拒绝（147步）。FCL拒绝与实际PhysX接触分别报告。最终完整重新规划替代了失败的补尾方法。

水果本轮两种预算优化尚未完整通过；不宣称三个任务的预算余量都已改善，也不把定点开发结果合并为新的跨种子成功率。当前版本仍需通过共同执行器的组合与持物检查，未成为联合双臂规划器。

回放报告有两个既有元数据问题：顶层 `official_200_step_complete` 缺省为false，而实际 `checks/outcome`、官方最终成功及 `<200` 步数均通过；原生持物审计显示标签在药瓶任务仍有apple/banana沿用名，语义对象pill_a/pill_b与原生H5键080_pillbottle_1/2的映射正确。此轮按实际动作及物理检查验收，报告字段整理另行处理。MPLib完整规划耗时应读 `planning_pipeline_wall_s`，`native_planning_calls.wall_seconds`只含初始screw调用。
