## 此前成功与本轮失败的关系

此前水果同盘的 cuRobo 成功案例为 seed401，完整执行及严格动作回放均为 196 步。本轮 seed401 仍为 196 步成功，seed403 为 199 步成功；没有找到 seed402 更早的运行记录。原始冷启动、复用及长序列中的两次 seed402 均于同一阶段失败，不能据此归因为跨回合复用引入退化。

三种初态使用相同的 `standard-8cm / fixed-task-v4 / standard` 配方、planner seed0、`task-default-v1`、`normal` 和官方 200 步时限。历史成功记录与扩展回归的范围见[复用验收](CUROBO-EPISODE-REUSE.md)。

## 原生复现与候选检查

在同一型号 GPU 上重新运行一例普通 seed402，保留四实例完整初始化、预热、回合重置及原执行链。外置 worker 观察器只在原生下降规划返回后捕获结果，不替换其返回对象或修改配置，不执行被拒绝的候选。

复现与原始失败具有相同初始状态内容、相同各阶段步数及完全相同的 `137×16` 动作。下降前双方的 `robot_cfg`、`world`、关节初态、TCP、payload 模型相同；payload 状态仅确认报告的来源 SHA 不同，其余内容相同。这一来源身份差异单独保留，不将两份报告混为同一原件。

原生规划返回 `path_valid=true`、`collision_valid=false`、`limits_and_dynamics_valid=true`。候选缓冲区为 1000 点，其中有效轨迹为 131 点，约 2.596 秒；其余点重复末态。诊断用独立成本对象和私有缓冲区读取原配置的检查值：

| 检查 | 实测 |
| --- | --- |
| 原配置 self collision | 全部有效采样点为零 |
| 原配置 world collision | 仅第 0–14 个有效采样点为正，缓冲区尾部为零 |
| 对归档 FK sphere 与冻结世界逐一做 CPU 几何检查 | 与原生碰撞分类一致；仅左臂 link5 的局部球161与右臂 link6 原生凸形状重叠 |
| 同一对完整实际凸碰撞形状 | 全部 131 点分离，最小间距约 31.81 毫米 |

唯一涉及的是 link5 局部球161／原生全局球1366。精确球心到完整三角形表面的距离复核得到最大代理重叠约 8.71 毫米，发生在候选第 11 帧；按原生权重重建世界成本，全程对应的穿透量误差不超过约 74 纳米。初次 FCL EPA 接触深度在个别帧有数值偏差，原始记录保留，代理深度采用单独的精确表面距离复核结果。

原配置的世界检查激活距离为零，`sweep=false`。因此上述结论覆盖候选离散采样点，不声称已经证明连续时间无碰撞，也不覆盖内部全部未选中尝试。原生世界成本是加权聚合值，不能作为毫米或碰撞次数解释。

实际仿真只执行到原来的 137 步；双果仍抓在手里，已有 685 个物理子步未记录禁止接触。原生复现保留 `failed` 和退出码 1；诊断完成不改变原评分。

## 为什么上一段搬运成功

`curobo_scene._cover_convex` 以 25 毫米网格的整格外接球覆盖完整凸实体。扩张半空间筛选保留了额外网格，球心可能在真实实体外；link5 球161的球心在真实表面外约 20.49 毫米，球半径另有约 21.65 毫米。

在实际下降起点，旧代理与对侧 link6 重叠约 7.21 毫米，完整实际凸几何相隔约 32.38 毫米。seed401／403 对应起点的实际间距约 47.55／52.82 毫米，均未出现该代理重叠。

每个阶段的规划都会刷新双方的真实位姿。上一段搬运规划时，对侧 link6 仍在搬运前的位置；相同左臂球161对旧快照有约 206.42 毫米间隔。两臂搬运完成，对侧 link6 平移约 316.41 毫米，新的快照才暴露这一代理重叠。保持刷新是正确的，不能通过沿用旧障碍位姿消除失败。

## 已检查的修复候选与后续范围

现有 `curobo_payload.tight_convex_spheres` 使用完整凸实体与网格的交集收紧球覆盖，只有证明为空的格子才删除。CPU 检查同样的 25 毫米网格得到：

- link5 从 387 个球降为 368 个球，保留完整实体覆盖证明；几何选择不依赖种子、姿态或障碍。
- 在捕获的 131 个原生候选采样点上，仅替换 link5 覆盖，涉及变化的世界及自碰几何对均分离；对侧 link6 的最小代理间距变为约 +14.84 毫米。这是几何反事实检查，尚未重跑原生求解器或闭环执行。
- 本机首次构造约 2.725 秒，缓存读取约 0.000671 秒，属于单次诊断耗时。

下一步可共用现有覆盖内核，为 link5 提供固定、可版本化的几何表示。payload 模块依赖 scene 模块，直接反向导入会形成循环，宜共享覆盖函数或在导出后做几何细化。应保留完整实体覆盖、碰撞权限、实时场景更新与原任务要求；随后验证三个种子、其他代表任务、失败后重置和动作回放。原始失败继续保存，修复后的结果另行报告。
