## 1. 目标、边界与当前起点

目标是把 The Imitator Game 扩展为持续接入新本体、新操作能力和新物理任务，并规模化生成高质量人类—机器人配对数据的平台。负责范围包括本体、规划控制、轨迹、物理环境、资产、数据和评测接口。**Real2Sim 重建由其他人负责**；本项目负责约定并接收其资产、场景、物理参数和任务语义输出。

保留 L0–L3：L0 保留运动过程，L1 保留物体最终状态，L2 保留任务语义，L3 通过替代对象保留意图。层级是**示范—执行配对的属性**，不作为策略输入；本体、协作、轨迹、物理对象作为额外维度，不命名为 L4。[官方层级定义](https://imitator-game.github.io/docs/levels.html)
