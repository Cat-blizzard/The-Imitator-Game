# 双臂扩展开发约定

修改本目录代码前，阅读仓库的[检查分层与质量配置约定](../../../../docs/tig-dual-arm/CHECKS-AND-QUALITY.md)。该约定依据用户确认的取舍，作用于后续双臂数据管线开发。

- 保留动作/指序/坐标系/起点/时间轴/关节限位等执行契约，以及禁止碰撞、实际失抓、掉落、释放和持物模型有效性的检查。
- 不继续堆叠全局固定距离、角度、等待步数或收敛余量作为一票否决条件。非执行契约、非明确物理失效的新检查先作为观测，评估误报后再决定任务内的接受规则。
- 抓稳/滑移参数应进入任务配置；退手距离和稳定观察窗作为可选质量要求。配置化时保证执行、回放与汇总读取同一版本，不能只改一处阈值。
- 区分代理几何疑似碰撞与实际碰撞，使用适用的精细复核；不得通过忽略真实禁止接触来处理误拒。失效的持物表示应更新、恢复或终止，不能继续假定有效。
- 独立报告官方成功/超时、实际执行与物理结果、数据质量及规划/预算事件；不把预算或可选质量不足写成物理失败。官方任务时限继续生效。
- 完整GPU读回、重复哈希和详尽子步归档主要用于验收/诊断。常规生成保留必要实时监测、动作、初态、版本/配置及必要事件。
- 保留历史协议、轨迹与原评分。新规则另存版本化报告，不追溯改判；不得把文档约定宣称为已经实现的运行能力。

当前完整入口仍有固定质量门槛，迁移任务见上述约定及仓库实施方案。本指引不要求在无关改动中顺带重构整条管线。
