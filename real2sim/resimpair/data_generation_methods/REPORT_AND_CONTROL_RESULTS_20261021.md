## 费用：能确认什么

通过现有私有配置在内存读取凭据，只做只读查询；报告、提示和演示文稿无凭据。查询了 [服务商报价](https://api.echoflowai.cc/pricing)、公开价格配置和账户接口。账户累计用量不能按本次实验归因，时间过滤未产生可区分结果；逐请求日志接口不接受现有 API key 身份。因此**本次历史视频人民币实际扣费仍未知**，不拿账户累计额当作本次成本。

- Nano 图像模型公开基础字段为 `$0.12923`，实际分组、分辨率与结算映射尚未确认。

## 双臂：两个 planner、同一个执行时钟

[实现与复现](dual_arm_candidate/README.md)复用两 Panda 水果场景及官方 MPlib：两臂分别规划，较短路径拉伸到共同 20 Hz 时间轴，两套命令在同一个 `env.step` 执行。另对同刻两臂与携带物网格加密检查，并记录每个 100 Hz 物理子步接触。它不是 14 自由度联合最优规划，也没有重写旧严格苹果规划器。

冻结预算为四次执行、最大并行 1、每次 1200 秒上限，仅 GPU2 渲染与 CPU PhysX。先固定两果升高、连续抓持、速度及禁止接触规则，再运行：

| 实际尝试 | 观察 | 决策 |
|---|---|---|
| 同步首跑 | 双 TCP 同时移动 4.45 秒；两果升高 18.6 / 16.9 cm；仿真 8 秒，进程 12.08 秒 | 末端物体线速／角速超限；稳定性失败 |
| 同源固定开度修正 | 根据实测开度减 1.5 mm，抬起过程丢果 | 否定该固定开度修正 |
| 同源串行对照 | 第二只水果抓持丢失 | 未形成成功配对对照，不能给提速比 |
| 预选新布局同步 | 另一对象索引的水果丢失 | 不能晋级为稳定双果操作 |

完整验收 **0/4**。独立审计首跑 172 个加密规划点、160 个实录关节状态无互臂网格碰撞，重合双臂的反例被拒绝；四次禁止接触峰值均为 0。有限采样不是连续碰撞证明。首跑未导出最后一次控制后的原生抓持矩阵，该字段保留 unknown，不能靠 runner 的通过字段补齐。

跨布局对象索引发生交换，已按实际网格 SHA 与资产 UID 做对应，见 `dual_arm/object_identity_correspondence.json`。一条轨迹的同步时段不等于稳定抓持质量，更不能把失败的串行与同步耗时作成功目标下的加速比较。后续应区分抓取几何与接触反馈的贡献；不降低稳定阈值、不换 seed 无限重抽。

## 灵巧手：实际接入 The-Imitator-Game

[候选实现](dexterous_candidate/README.md)把现有 Panda 7 关节与 Allegro 16 关节通过声明的固定适配器组合，接入 23 维控制。新增 [The-Imitator-Game 独立入口](../The-Imitator-Game/examples/dexterous_candidate/replay_panda_allegro.py)，实际绑定其 ManiSkill / BaseEnv / BaseAgent 源文件与 SHA；Python 环境和资产复用 PolicyGen，不称为资产自足移植。

完成一次模型加载探针与三次完整物理执行：原动作、修正接触测量后的同动作复放、The-Imitator-Game 后端复放。是一套动作计划的三次执行，每次 300 条命令／301 状态、15 秒仿真、两同步视角；最后一次进程 29.21 秒，三次合计 77.78 秒。没有三条新动作覆盖。

实际结果是推动方块 6.12 cm 后空抬。补齐原测量遗漏的固定指尖后，中指尖峰值 7.71 N、拇指接触 0；方块最大升高约 0.076 mm，不满足 5 cm、拇指＋另一指接触及连续稳定保持的冻结标准。状态逐元素复放一致，测量修正没有改变动作或物理结果。旧原始 0 N 记录保留，不能解释为无接触。

进一步资产核对发现源 Allegro **13 个 link 违反主惯量三角不等式，最大相对违反 28.23%**；源张量保持不变，PhysX 加载后的实际处理未导出。这使当前候选只能证明接口与执行接通，不能通过动力学资格。下一轮优先核对惯性／适配器和实际运行张量，再做拇指对置与接触反馈；当前未做全臂独立路径碰撞资格。

静态盘点另外确认的是 UR10e＋Shadow（不是 UR5）、XArm7＋Ability、Realman＋双 Inspire；不把这些现存注册或资产文件算成本轮已验证的新本体。XArm7＋Shadow 的声明 URDF 路径缺失。UR10e 旧 `is_grasping()` 无条件 True，不能用作独立成功证据。

原始 NPZ 的 `actions[0]` 是未执行且不同关节顺序的初态占位，`actions[1:]` 才是 300 条实际命令；原文件未改，另存有效行 mask 和顺序说明。

## 验证、资源与版本决策

独立审查位于 `report_control_20261021/control_independent/`，含首跑互臂网格重建、其余三次失败复算、The-Imitator-Game 后端来源／惯性复查及 PPT 视频来源核对。新增 8 项 CPU 测试验证同刻路径拉伸、固定臂对照、配对加密和开度映射。完整软件回归分两个不重叠目录执行：`data_generation_methods/tests` 为 714 passed / 13 subtests（17.61 秒），`data_generation_methods/r2h_pipeline` 为 64 passed / 5 subtests（62.61 秒），合计 **778 passed / 18 subtests**；日志为本轮 `integration_pytest.log` 与 `integration_r2h_pytest.log`。软件通过不能替代物理资格。最终 PPT 独立审计确认 14 页、7 段视频来源哈希一致，两个措辞修订生效，未发现凭据或账户累计账单数值。

新代码全部在候选目录或独立入口，旧生产默认不变。保留同步执行与本体控制接口作为实验候选，放弃本次固定开度修正；没有稳定抓持或新有效合成人类数据的晋级。已有多视角、人物／状态准备和历史失败回归仍保留。

当前影响有效产率最大的证据指向人物与对象条件错误及审核漏检；视频数分钟延迟会放大返工成本，但不是唯一主要瓶颈。新接触机制的抓持控制和资产动力学是控制侧明确缺口。后续优先在已有本地证据上做可区分的修正；付费生成继续保持零预算，长期目标未完成。
