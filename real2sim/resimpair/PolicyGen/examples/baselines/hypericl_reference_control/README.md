# 相同起点下，参考视频能否决定机器人动作？

这是顺／逆时针持勺运动的独立诊断实验，不是原 Imitator Game 榜单测试，也不代表已学到流体动力学或完成了人类到机器人迁移。先构造必须利用参考才能区分的两种动作，检验参考是否通过生成参数影响行为。已有三教师预训练独立继续，本实验不改它的源码、数据或运行进程。

## 数据与物理核验

- 原生 `TwoRobotStirSpoon-v1`、双 Panda、固定 zed2i RGB，物理执行原生 PD 关节命令。共同抓取前缀由规划器执行；学习与评估从已持勺的共同状态开始。
- **同一布局的两种方向具有完全相同的分支 RGB、关节状态和物理状态 SHA256。** 方向仅用于选择示范和离线评分，不作为网络输入，不利用目标相关 reward/done 提前终止。
- 目标为 100 个有效布局 × 两个方向 = **200 条实际执行轨迹**，训练 60/验证 20/测试 20 个布局。另一个资格检查布局不进入这三组。每组候选种子提前固定，最多尝试两倍候选，只按专家实际执行是否合格接纳，记录所有拒绝；不足配额则停止，不启动训练。
- 两种方向均围绕碗中心、半径 2 cm 执行三圈。原采集高度 21 cm 时顺时针会掉勺；两方向共同提高到 24 cm 后资格检查通过。高度相对碗物体原点，**不是勺尖高度**。此前失败样本和日志保留，没有改变原环境实现。
- 每条轨迹保存实际 RGB、原生指令、当前关节、实测 TCP、勺子位姿、抓取状态、公共前缀和视频。读取环境真实控制频率，目前为 **20 Hz**，训练、评估输入的动作时间间隔及视频帧率保持一致；FK 与仿真实测 TCP 必须误差 < 3e-6。标签使用实际下发关节目标的 FK，相对查询时刻实测 TCP，不把规划目标当成实测轨迹。
- 动作保持现有 `panda_eef14_v3`：每臂 `[dx,dy,dz,rx,ry,rz,open]`，平移米、旋转向量弧度、张开程度 0–1。16 步 chunk 全部相对同一个查询时刻、各臂各自 TCP 坐标系。机器人状态仍含关节本体感知；它不是关节动作监督。

## 两个训练组

| 项目 | 正常参考 | 固定参考对照 |
|---|---|---|
| 初始参数 | 同一 A16 全参数 checkpoint | 完全相同 |
| 参考 | 同方向、不同布局的机器人视频 | 训练集所有视频特征的固定均值 |
| 机器人查询、动作标签、采样顺序、FM 噪声 | 两组一致 | 两组一致 |
| 损失 | 只有 action flow-matching MSE | 同左 |
| 训练参数 | E/T/R/D 与原 CNN/EEF 策略可训练部分 | 同左 |

参考采样 32 帧，冻结本地 DINOv2-L 最后一层提取特征；E 的时间位置沿用旧 10 帧参数并插值。沿用 E/T/R/D、CNN 和 EEF 维度，D 生成完整 W **和 b**，此诊断统一采用 `reference_only` 条件，生成参数不依赖当前机器人观察。固定参考组也正常训练生成器，不是在测试时临时替换参数。

共训练 10 epoch，batch 32。Hypernet 学习率 1e-5，其余机器人模块 1e-6，AdamW；无腕部、未来帧、专家蒸馏或参数幅度辅助损失。每个 epoch 遍历全部布局的轨迹帧对，较短方向循环到较长方向长度；再加原帧对数 1/3 的共同起点重复采样（占最终查询的 25%）。重复查询不是新增视频。每组执行完全一致的 schedule。每个 epoch 保存 checkpoint。

正常参考同一 batch 的不同查询可以共享一组生成参数。评估对每个回合只生成一次参数，全回合保持不变；机器人观察和动作采样每步更新。每对目标共享相同动作噪声，没有方向 ID、布局种子或时间步输入。

## 自动评估与判读

第 1/5/10 epoch 在相同 4 个验证布局评估每组，共 8 回合/组/次。第 10 epoch 在全部 20 个测试布局评估：

1. 正确参考：相同方向、不同布局的示范。
2. 相反参考：仅换参考方向，检查实际动作是否随之翻转；同时记录原目标成功率与**提供的参考方向**成功率。
3. 同目标换参考：另一个布局、同方向，检查对视频细节是否稳定。
4. 平均 W：用训练集参考生成 W 的均值，**保留当前参考的 b**，用于区分 W 与偏置的作用。
5. 固定参考训练对照：使用训练时的固定参考。

两方向均固定执行 600 步，使用原 EEF→IK 与 16 步时序聚合；不按目标成功截断。主指标：实测持勺 TCP 至少完成目标方向一圈，方向纯度 ≥90%，有效运动比例 ≥80%，持勺比例 ≥90%；同时保存约三圈（2.5–3.5 圈）的次指标。主指标不考“数三圈后停止”，因为当前策略没有跨整段运动计数的循环记忆。持勺 TCP 是操作运动指标，不是液体流动或勺尖接触力测量。

核心是 **同一布局两个方向都完成的比例**，不是只看平均单回合成功率。固定参考在确定性执行和相同噪声下无法区分两个目标；若正常参考两方向都成功、反向参考能翻转动作、同向换参考稳定，才支持“参考控制行为”。若平均 W 不降而换参考有效，需要继续排查 b 的作用，不能宣称 W 学到了信息。失败时先查离线分支拟合、坐标转换、IK 与闭环偏离，不能直接归因于数据规模不足。
