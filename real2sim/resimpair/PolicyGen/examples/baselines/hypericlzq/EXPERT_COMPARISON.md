# EEF 专家监督对照（2026-09-26）

## 对照的含义

两组都从同一个 `staged_eef_v32_20260926/base/best_panda.pt`（base 第 6 轮）开始，保留 FP32 LoRA/attention 修复、生成增量软正则、异常停止保护、相同特征缓存和 EEF 动作标签。

| 组 | 专家准备 | hyper | joint |
|---|---|---|---|
| A：control | 无 | 原始数据 20 epoch，无专家监督 | 相同混合课程 20 epoch |
| B：expert | 冻结基础策略，任务 LoRA 库训练 10 epoch | 原始数据 20 epoch，加参数/函数监督 | 相同混合课程 20 epoch，保留冻结专家的函数监督 |

专家额外训练开销单独计算。这是固定学生训练预算的对照，不是等总计算量对照。两组不重新训练基础策略；初始 atoms 也保持相同，第一版不额外做专家 SVD 初始化，不混入该变量。

专家库消融不能取代数值问题修复。幅度正则只限制更新过大，专家提供任务相关的更新方向和行为。是否改善 seen/unseen 成功率必须用闭环测试判断。

## epoch 与 checkpoint

- hyper：一轮遍历原始 3,000 条机器人轨迹的 1,033,711 个查询帧；有效 batch 256。
- joint：一轮按期望采样 1,033,711 个原始任务查询计量；记录实际原始查询等价 epoch。原始数据比例从 90% 渐变到 70%。不是把全部外部数据遍历一次。
- expert：每个任务的原始录制按组固定留出 10% 用于专家准入，其余 90% 录制的查询帧完整遍历一次为一轮。留出数据只用于专家准入，不是 benchmark 测试集，也不会从学生的训练数据中删除。
- 每 5 epoch 保留 checkpoint，每个阶段保留 last/best；日志和 status 每次刷新都包含小数 epoch、总 epoch 和预计时间。
- `--stop-after-epoch 3 --epochs 20` 在绝对第 3 轮暂停，但学习率继续采用完整 20 轮预算。继续训练用 resume，不能 weights-only 重置进度。

## 专家怎样训练、怎样选

`train_experts.py` 冻结整个基础策略、观测编码器和动作适配器，只学习每个任务的 LoRA A/B 和 AdaLN bias。初始 A 随机、B=0，使专家初始恰好等于基础策略。目标是原来的 masked flow-matching action loss，加同样的更新幅度软正则。

注册键为 `(goal_key, target_action_space, source, label_kind)` 的稳定标识，不使用不同 manifest 各自重排的 goal_id。参考视频的人类/机器人本体不决定选哪个专家，目标 query 的机器人和动作标签决定。任务 ID 不传入学生策略，只用于训练教师选择。

每个专家用留出录制中的 64 个固定查询、相同噪声和时间，对比专家与基础策略的 flow MSE。至少 32 个有效查询，且误差至少降低 2% 才启用。未过准入的任务仍正常训练 action loss，不强制学习不合格专家。这个准入是离线误差筛查，不代表专家已经通过闭环成功率评估。

## 学生损失

保留 action + 0.02 task + 0.02 consistency + 0.01 parameter（原有幅度正则），hyper 阶段增加：

```
0.2 expert_param + 0.1 expert_dir + 0.05 expert_mag + 0.2 expert_func
```

专家监督在第一轮由 0 线性升到完整权重。无匹配、未准入或没有动作的 query 不蒸馏。

- 参数监督比较完整 `ΔW`，不是单独比较 A/B：后者有缩放/基变换不唯一的问题。用低秩 Gram 乘积精确计算矩阵差异，节省显存。
- `expert_param` 是相对矩阵平方误差；分母以基础权重范数的 1% 为下限，防止近零专家导致相对误差爆炸。方向和对数幅度损失忽略近零的教师层，AdaLN bias 另加均方误差。
- 与原版一样，只对 global program 进行参数监督；逐观测阶段残差通过 action/function loss 学习。
- `expert_func`：同一个观测、噪声动作 `x_u`、去噪时间 `u`，比较学生和专家的 flow 输出，在有效动作维度/时间上算 MSE。它不是物理机械臂速度。所有蒸馏梯度只回到学生。
- joint 会更新基础策略和动作适配器，旧 `ΔW` 与新基础参数不再对应，因此关闭参数/方向/幅度对齐，继续用独立冻结的完整专家模型做函数监督。教师基础 checkpoint 有 SHA256 校验；恢复训练时也校验 bank 文件哈希。

## 新数据适配

第一轮对照只建立原始 15 任务、Panda EEF 的专家，避免同时改监督和数据量。joint 的原始/额外 Panda/OXE/AgiBot/EgoDex/无动作视频配比对两组完全一样。只有匹配的已准入原始任务 query 得到教师监督，其余样本继续已有动作或视频辅助任务。

接口支持用 `train_experts --sources ...` 建立额外机器人的专家库，但必须先用 joint checkpoint 训练好这些机器人的动作输入/输出适配器，不能冻结尚未训练的适配器后就声称得到了外部数据专家。新库在相应数据内按录制组留出、按目标/本体/标签类型分组和准入；稀疏目标少于 5 个录制组暂不建专家。不同来源的专家可先分别做行为蒸馏；不要直接把旧基础策略上的 delta 硬套到另一个基础策略。

人类参考视频可以指导机器人 query；无 action 人类视频只做参考和未来特征/顺序等辅助任务。人类手腕估计仍是独立动作空间，不被当成机器人真值命令。

## 评估协议

对齐两组的 hyper/joint 第 5、10、15、20 epoch：原任务 seen/unseen 闭环成功率、正确/错误参考差距、固定动作误差和生成增量范数。仍每 32 个控制步才更新整套 hypernet 生成参数。原版关节动作模型的历史成功率不能直接作为这个 EEF 消融的等价对照。

首次代码验证：70 项单元测试，另有真实缓存数据的编译训练、专家/学生 epoch 边界恢复以及学生 128×2→256×1 恢复测试。真实数据小测试里的强制准入 teacher 明确标记 TEST_ONLY，绝不用于生产对照。
